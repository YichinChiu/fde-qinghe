# 公开预检样本

这些记录和期望结果供检查代码接口使用。请核对编号格式、字段解析、合法标签保留、异常记录去向、重复运行和对账结果。

预检只输出通过与否及失败层次，正式核验另有未公开的样本。结构检查通过后，还需要结合真实运行说明数据范围和判断依据。

仅经客户确认的标准标签进入标签表。本样本的“待核新品”是备注，原文和来源必须保留；它不是新增标准标签。备注预检按同一来源记录比较：各条 note_text 按原顺序拼接，去掉分隔标点和空白后，非标签文字不得遗漏；raw_text 与来源完整保留，触达限制全部识别。分段边界与其他类别交人工审阅。expected.json 中备注行展示一种可行写法，不限定必须分成相同条数。
