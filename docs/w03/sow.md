## 背景与优先级判断

**客户的问题。** 青禾的业务目标是应对复购下滑（`materials/w03/08_业务目标与工作清单.md`）。W02 调查时，复购率口径“口径未定、牵头方未确定”，各角色都指不出由谁核定（`docs/w02/business_model.md` 2.5）；小林手工维护的 Excel 不能当作公司统一口径。在数都对不上的情况下，任何“圈人、触达、证明收益”的工作都没有可核对的起点。

**本期为什么先做“可核对的问数”。**（我方判断）

1. 依据已基本齐备：38 项报表指标在订单日报说明、财务邮件、运营周报和本期统计确认邮件中已有定义，缺的是付费会员资格的少数规则，本周已通过访谈补齐到“运营口头答复待书面确认／本期暂定口径”的程度。
2. 能直接减少重复核对：小林的痛点是“整理名单、准备报表、反复核对信息”（08 材料）；同一口径、可追溯定义、可复现查询，是减少反复核对的前提。是否真的节省工时，本期未测量，不作承诺。
3. 风险可控：本期只查数、解释，不打标签、不发券、不联系会员、不改系统记录，符合 W02 已确认的授权边界（小林“没有授权它自动发券、联系会员或改记录”；沈总同意第一阶段不直接打标签发券）。
4. 后续工作依赖它：按条件筛选会员、运营建议都需要先有一致的会员、订单和付费资格口径。

**不据此承诺的内容。** 查询和校验正确只说明指定测试范围内定义可追溯、查询和校验正确，不等于复购率提升或投资回报（王经理 MSG-03537）。本期使用合成测试数据，不对业务增长作任何承诺。

## 本期、后续与排除范围

### 本期交付内容

1. **38 项报表指标的指标库**（32 项通用报表指标、6 项付费会员月度指标），每项有中文目录、单位、定义来源引文、查询限制和可执行定义：`artifacts/w03/library/`。
2. **在原运营 Agent 聊天入口按青禾口径问数**：自然语言提问 → 生成并执行查询 → 解释结果；明确时段才查，含糊问题澄清，越界、未定义指标和不支持的组合返回不支持，不以零代替；零分母返回“未定义”。
3. **支持的查询范围**：时间为数据覆盖期 2024-09-01 至 2026-09-01（不含）内的任意日期区间；可按成交门店及其地区／名称、会员归属地区／名称、订单渠道、订单状态、会员等级、会员账户、日或月分组和筛选（按指标实际可达路径）；6 项付费会员月度指标与 3 项月内复购指标只支持完整自然月、全渠道、全门店，多月按月分别列出。
4. **校验能力**：独立期望（逐记录审核程序）、确定性判定程序及小样本与规模数据的校验报告。
5. **定义与核定记录**：业务模型、指标核定与未决记录、访谈与核查记录。

本期交付内容**不含按条件筛选会员**（圈选名单），验收时不计入本期（王经理 MSG-03541）。

### 本期关键统计口径（同时写入 `docs/w03/metric_decisions.md` 与指标目录）

1. **有效订单**：paid 状态且实付大于累计退款；取消、全额退款不计有效购买；退款按原订单下单日期归属（02 财务邮件）。金额以整数分存储，展示元须换算；零分母未定义，数据覆盖之外不是零。
2. **月末付费会员六项**：按自然月**月底最后一天**判断资格；先选月末有资格的账户，再统计这些账户**当月全渠道、全门店**的有效订单；不要求每笔订单发生当天已具备资格；按账户资格筛选，不按卡重复（04 本期统计确认邮件；王经理 MSG-03545）。
   - 卡种范围：悦享年卡、家庭季卡；联名卡、体验卡不算；等级和付款金额不代替卡种与有效状态（运营口头答复，待书面确认）。
   - 权益开始日落在月底当天：月末才生效、但当月此前有购买的账户，才纳入当月有效购买（运营口头答复，待书面确认）。
   - 计划结束日、提前终止日落在月底当天：当天不算有效（本期暂定口径，依据门店实际做法，待运营与 IT 核对确认）。
3. **月内购买、复购与付费会员六项的查询限制**：只支持**完整自然月、全渠道、全门店**；查询多个月时**按月分别列出**，各月去重人数**不跨月相加**当作跨月人数；暂不按门店或渠道拆分付费会员月报（03 会员运营周报、04 邮件）。
4. **复购率**：分母为同月有效购买账户，不是全部注册会员（03 周报）。
5. **观测期首购**：先用全测试覆盖期历史确定每个账户的首笔有效订单，再按查询窗口筛选；不代表终身首购（03 周报）。

### 本期验收的含义与分工

- 本期验收只说明**指定测试范围内的定义可追溯、查询和校验正确**；它与复购率是否提升、投资回报是否成立**分开确认**，不能据本期验收认定复购已提升（王经理 MSG-03537）。
- 分工：**运营**核对业务范围；**王经理**核查统计口径与验收依据；**IT** 核对字段和数据覆盖（王经理 MSG-03537、03543）。
- 预算金额、合同签署和正式上线不在本期验收内，另行确认（王经理 MSG-03537、03545、03610）。

### 后续阶段（本期不做，另行约定）

1. **按条件筛选会员**：支持哪些条件，在这项能力交付时以书面范围确认为准；业务范围由运营（小林）牵头书面确认，字段和数据可用性由 IT（老周）书面确认；超出确认范围的要求按变更处理（见“变更处理”）。
2. 运营建议、名单使用与执行记录（需先议定门店是否参与、名单是否下发、人工确认机制）。
3. 生产数据接入、清理、导入、联调和权限（老周：“生产数据清理、导入以及联调时间另行安排”）。
4. 收益验证（复购是否改善、ROI），需另定观察方式与基线。
